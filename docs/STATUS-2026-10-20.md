## 1. Was MOCA ist

Rezeptbuch + Angebote + Einkaufslisten + Essensplan in einer kleinen Web-App.
Läuft auf **openclaw** als systemd-User-Dienst, kein Docker mehr.

| | |
|---|---|
| Dienst | `moca.service` (systemd `--user`, openclaw) |
| Port | `3001`, gebunden an alle Interfaces |
| Repo | `~/services/moca` (Branch `main`) |
| Prozess-Start | `server/src/index.js` |
| Log | `~/.local/state/moca/moca.log` |
| LAN | `http://192.168.178.69:3001/recipe/` |
| Tailnet (HTTPS) | `https://hermes.mara-palermo.ts.net:8443/recipe/` |

`/` leitet per 302 auf `/recipe/` um — der React-Router läuft mit `basename="/recipe"`,
ohne den Pfad rendert die App eine leere Seite.

## 5. Wichtige Endpunkte (Auswahl)

**Angebote** (`/recipe/api/offers` …)
- `GET /offers` — aktueller Cache (`offers` je Kette + `lastUpdated`)
- `POST /offers/scrape` — Scrape starten (409 wenn schon einer läuft), `GET /offers/scrape/progress`
- `POST /offers/match` — `{items:[{item,amount,unit}]}` → beste Angebote je Position (max. 250)
- `GET /offers/match?listId=` — dasselbe für eine gespeicherte Liste
- `POST /offers/price-summary` — `{items:[{name,brand}],days}` → min/max/Ø/Verlauf
- `GET|PUT /offers/region` — PLZ lesen/setzen (schreibt `offers-config.json`)
- `DELETE /offers/clear` — Historie löschen ⚠️ ohne Auth

**Merkliste** (`/recipe/api/favorites`): `GET`, `POST {name,brand,target_price}`, `DELETE`

**Rezepte**: `GET /recipes/:id/week-cost` — Angebots-Summe + Preis pro Portion

## 6. Logik, die man kennen muss

**`offerClassifier.cjs`** — 12 Warengruppen + Ernährungs-Tag, rein heuristisch.
Erste Treffer-Regel gewinnt, deshalb Overrides für Komposita
(`Weizenmehl` ≠ Weizenbier, `Eiscreme` ≠ Drogerie-Creme, `Teewurst` ≠ Tee).
Kurze Keywords (≤4 Zeichen) matchen nur an Wortgrenzen.

**`productMatch.cjs`** — gemeinsam genutzter Matcher (Rezepte, Einkaufsliste, Scraper):
Stammvergleich, Kopfwort-Regel für deutsche Komposita (`Magerquark` ✓,
`Quarkbällchen` ✗), Ausschluss von Fertiggerichten/Sorten, Treffer nur ±0,15 um
den besten Score, Duplikate raus. Der alte `fuzzyMatch` (Substring, `score > 0.3`)
ist für diese Zwecke abgelöst und wird nur noch exportiert.

**`recipeCost.cjs`** — summiert **Packungspreise** der Zutaten, die im Angebot sind.
Keine Gramm-Hochrechnung; das steht auch so in der UI.

## 10. Bekannte Lücken / technische Schuld

1. **Keine Authentifizierung.** Jeder im LAN/Tailnet kann `DELETE /offers/clear`,
   Scrapes starten oder die PLZ ändern. Bisher unkritisch (nur privat), aber der
   stärkste Kandidat für einen Review-Fix.
2. **Kettenlücke ist regional**, nicht technisch: Aldi Nord/Marktkauf/Combi/V-Markt/
   Feneberg liefern für 56377 keine aktuellen Prospekte.
3. **„Sonstiges" 14,5 %** — Long Tail (Deko, Saisonware, Marken-Namen).
4. **Produktbilder:** Marktguru liefert im `images`-Feld keine URL, nur Metadaten;
   `storeAddress` ist bei Bundes-Prospekten `null`.
5. **Store-Label-Maps** existieren doppelt (Client `STORE_LABELS`/`STORE_COLORS`,
   Server `storeDisplayName`) — driftet leicht auseinander.
6. **PWA** hat Manifest, aber keinen Service Worker (bewusst zurückgestellt).
7. **Kein ESLint/Prettier** im Repo; Qualitätssicherung ist `npm test` + manuelle Checks.
